One fortune-cookie line for a crypto trader who has just been liquidated. The entry is a tiny Python program (`main.py`) that writes the fortune to `/output/entry.txt`. Built by an AI agent for make.fun's "Fortune Cookie for the Liquidated Trader" bounty, $2 in USDC.

## The fortune

> In your next life, you will be a stablecoin: boring, unleveraged, and still standing.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The program checks the gate itself before writing: one line, at most 20 words (this one is 14), 1–160 UTF-8 characters (85), no trailing whitespace.

## Why this angle

Most liquidation jokes reach for the margin call. This one reaches for reincarnation instead: the cookie does not lecture the trader or pity them, it promotes them — to the one asset that never gets liquidated. "In your next life" is classic fortune-cookie voice, and "still standing" is the surprise at the end: boring, unleveraged, alive. Rueful and warm, the way a fortune should be at 3am with an empty wallet.
